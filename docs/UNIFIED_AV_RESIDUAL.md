# Optional residual A/V head: untested quality hypothesis

`architecture="compact_unet_av_residual"` adds a small specialized conditional
artery/vein correction while retaining one RGB network. This is an isolated
scratch-initialized architecture experiment, not a selected model or a claim of
better results. No GPU trial has been launched. Existing compact/pilot/original
model behavior and state keys remain unchanged.

## Architecture and exact initial state

The compact encoder, decoder and existing five-logit `head` keep their original
state names. `UNet.forward_features` exposes the padded decoded frame; both the
original head and residual branch run before cropping to the original H/W. The
baseline forward remains numerically identical to the frozen pre-refactor d83
forward on even/odd rectangular inputs, including training BatchNorm buffers.

The optional branch concatenates decoded features, the same centered RGB input
(replication-padded to that frame), and the **detached** internal vessel sigmoid.
It uses two 3×3 conv → GroupNorm (1 group) → SiLU blocks, then a 2-channel 1×1 conv.
Hidden width is max(8,base_channels). The last conv weights and biases start at
zero, so all five initial logits exactly match the baseline at matched backbone
weights. The two corrections add only to logits 1/2; vessel/disc/cup remain direct
base-head outputs. No external vessel mask, second network, teacher initialization
or pretrained downloads are introduced. Detaching the internal vessel feature
prevents a new conditional-loss shortcut into the vessel output row.

Extra-head initialization uses a private CPU seed (global initial_seed + 104729)
inside fork_rng(devices=[]), then restores the original CPU RNG stream. CUDA RNG
is not seeded or consumed by this initializer. Thus a matched-seed baseline keeps
both identical initial backbone state and the same subsequent crop/augmentation
RNG stream. The extra head is deterministic at a given seed without borrowing
subsequent crop draws. Its first hidden-layer gradients are zero at the first
step because the final conv is zero; the final layer immediately receives valid
A/V gradients and can subsequently pass gradients upstream.

parameters are exclusively under `av_residual.*`. The new module is included in
the executable training-source fingerprint. Safe unified checkpoint loading
reconstructs the architecture from its config, including on odd image geometry.
The existing lineage marks it scratch/independent-model-eligible; trying historical
initialization for this architecture is rejected by the existing guard.

## Supervision and scope

The existing masked V/D/C BCE+Dice and known-class conditional A/V CE, probability
fusion, vessel-gated argmax and cup containment are unchanged. No residual-head
gradient is generated by vessel/disc/cup-only, partial or ambiguous A/V labels.
Valid known-class A/V supervision provides its gradients. This is a gradient
statement: the unchanged AdamW policy may still apply weight decay to parameters
with zero gradient. Changing residual-head parameters at a fixed backbone cannot
change V/D/C logits. Joint training can still change shared features and therefore
all task results; no preservation of their trained validation quality is promised.

## Single-change protocol, pending review and cache E1 gate

Motivation supplied by the current validation evidence: LR 0.0003 at E8 had
artery/vein Dice about 0.561/0.615 and conditional accuracy 0.653, while calibrated
original models were about 0.690/0.697/0.749. These are motivation, not a controlled
architecture comparison or evidence that this proposed head closes the gap.

After review and the fresh cached width 16 E1 preservation/QA gate, derive the full
candidate config from the exact accepted LR 0.0003 control config. Change **only**
architecture from compact_unet to compact_unet_av_residual. Preserve all other
values: seed 42, lr 0.0003, widths/depth/norm, partial labels, physical legacy25_raw geometry,
augmentation, batch/patch sizes, source/task sampling, fixed epoch_samples,
coverage-first policy, optimizer/weight decay, loss weights and scheduler horizon.
Do not shorten the planned scheduler horizon to 8; use stop_after_epoch=8 just as
for the matched baseline. Fresh runs only; never migrate old optimizer states.

Both fresh control and candidate should use the same newly frozen source and
canonical/cache pins. A historical LR 0.0003 E8 run may be shown as contextual
reference, not automatically treated as a same-source causal control. Freeze
new config/source/plan fingerprints only after review; none is predeclared here.
No existing immutable checkout, plan or ongoing training is changed.

Predeclare validation macro_dataset_mean_dice as the existing selection score;
report artery/vein Dice, conditional and end-to-end A/V accuracy, all V/D/C Dice,
per-dataset support/results, parameter count, actual train/validation/wall times
and convergence curves. Keep threshold 0.5 and inference geometry/tiles unchanged.
Do not tune on test data. Treat 8E as a bounded architecture screen, not the final
benchmark; proceed to a matched longer budget only if the validation evidence
justifies it. No improvement, latency benefit or determinism guarantee is claimed.

## CPU verification

`tests/test_unified_av_residual.py` checks a frozen original forward (pilot output
counts 1/2/3 and unified 5), even/odd shapes and BN buffers; identical initial
backbone/logits/RNG; head-before-crop ordering; V/D/C invariance to residual changes;
valid/invalid/partial/ambiguous A/V gradients and detached vessel conditioning;
first-step zero-head learning; safe checkpoint roundtrip; scratch lineage and
source fingerprint inclusion. Existing engine/unified regression tests are run
with the experimental source via PYTHONPATH, CPU-only. Temporary synthetic
checkpoints are functionality fixtures, not trained quality artifacts.
