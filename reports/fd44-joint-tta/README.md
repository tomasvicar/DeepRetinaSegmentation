# fd44 + experimental inference TTA compatibility

This separate research branch applies the exact inference-TTA change3548264 onto frozen fd44. The scientific implementation commit is e1fd202. It adds the four explicitly named modes `none`, `flips2`, `rot4`, `dihedral8`; no config/dataclass fields, sampler, architecture, loss, training loop, optimizer, geometry or photometry/cache operators were changed. No active/frozen worktree or operational protocol is retargeted. This is not a product merge or quality improvement claim.

Default `none` calls the original float32 prediction arithmetic directly, adds no inference report fields and makes no RNG calls. The focused suite verifies exact default probability/RNG parity, source72 raw training-step parity, BF16 safe-checkpoint compatibility, float32 inference under an outer BF16 autocast context, synthetic odd rectangular shapes/inverse transforms, joint AV weighting and zero-vessel handling, unchanged evaluation GT-support/annotation tracing, once-only full-image photometry and once-only verified-cache RGB reads before all eight views. Synthetic CPU forwards/tests are the only model execution; no actual TPE checkpoint forward, real TRAIN/VAL/TEST pixels, GPU job or operational deployment was performed.

TTA rotates/flips the full prepared RGB01 image **after** its saved photometric profile has been applied once, before tiling. Each model result is converted to vessel-weighted joint A/V probabilities, inverse-aligned on the full prepared grid, averaged in float32 and converted back to conditional A/V. The existing original-frame geometry restoration still interpolates joint A/V before recovering conditional probabilities. FOV masking and the final inverse geometry follow the existing order. Conditional A/V are never averaged independently of vessel confidence. All eight views preserve the full image shape after inverse alignment; tiling/whole-view interpolation may still make a real model non-equivariant, which is the intended measured experiment.
