# Optional unified tile batching research

This branch starts from frozen1f723 and changes only unified.py and the research validation-evidence API, plus focused tests/notes. No training configuration/dataclass, architecture, loss, scheduler, sampler, augmentation, photometry or cache code changes. No product CLI flag/app port is included. Frozen1f723/source72 and actual Ada trial6 are untouched. There is no default promotion.

`predict_probabilities`, `predict_unified`, `evaluate_unified_model` and `produce_validation_evidence` accept the optional research-only `tile_batch_size`1/2/4. Default1 omits new kwargs/metadata and calls the unchanged original single-tile function. Its AST and exact outputs/RNG match frozen1f723 for patch/whole and all TTA modes. Nondefault whole-view inference explicitly rejects; batch1 whole behavior is unchanged.

Batch2/4 keeps the original y-then-x tile enumeration and original sizes. It groups only consecutive equal-shaped tiles within one prepared TTA view, flushing on shape change or the configured bound; it does not pad/resize tiles to fit a group or batch across TTA views. It calls the model in float32/no autocast, applies the same float32 sigmoid/softmax joint A/V activation, then accumulates each individual prediction in the original enumeration order with identical strictly-positive Hann weights and float32 arrays. The existing full-image TTA inverse/joint averaging and original-frame joint A/V regridding/FOV masking remain unchanged. Full prepared photometry/cache reading stays once per image outside all tiling/TTA.

Batching changes convolution backend work grouping, so batches2/4 are mathematically equivalent but not promised bitwise equal on every backend. CPU tests use coordinate-sensitive odd rectangles and native BN/GN eval models, source72-style BF16 metadata with float32 prediction, nested autocast disabled, short/variable edge shapes and vessel-weighted A/V overlap. Eval buffers/parameters/gradients remain unchanged. Tilebatch1 is exact. No actual trained checkpoint forward, real-image/GT/TEST decoding, GPU benchmark or operational deployment was performed.

Nondefault size gets a separate `tile_batching` protocol block (requested bound/grouping/accumulation/FP32/experimental/not standalone certification). Batch-only fresh VAL evidence uses `experimental_unified_tile_batch_validation_evidence`; combined TTA remains explicitly experimental TTA evidence with the additional tile protocol. Existing selection/completion gates are unchanged. Ordinary default1 report schema stays unchanged.

The broad training-source digest changes because unified.py is fingerprinted even though the training functions are unchanged. Do not resume or retag any frozen source72/fd44/1f723 TRAIN run with this evaluator. A future benchmark/evaluation must pin this new source identity separately from original checkpoint training3725. Existing raw/CLAHE/LC operator/cache bytes and identities are unchanged.
